    Client API for employee requests

    Your HR, travel or expense applications can create employees and send requests. Create a token with the Client application scope under Settings. It can only use these endpoints; it cannot read documents, see the AI advice, decide anything or open reports.

    Every endpoint, field and status code is described in API.md in the repository. GET /api/v1/request-types lists the request types and their fields, so a client can build its forms from it.
